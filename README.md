# Learning Management System (LMS) - Prototype

This project is a **prototype Learning Management System (LMS)** built using Spring Boot.  
It is currently in early development and serves as a foundation for a full-featured LMS platform.

---

## 📌 Overview

The system is designed to eventually support core LMS features such as:
- Course management
- User enrollment
- Lesson/content organization
- Role-based access (Admin, Instructor, Student)
- Progress tracking

At this stage, the project focuses on setting up the backend architecture and core modules.

---

## 🚀 Technologies Used

- Java
- Spring Boot
- Spring Web
- Spring Data JPA
- Maven
- MySQL / H2 Database (planned or in use)
