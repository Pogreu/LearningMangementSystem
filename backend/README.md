# Spring Boot Backend Project

This is a simple backend project built using **Spring Boot**.  
It is created as a learning project to understand how REST APIs work and how backend systems are built using Java and Spring Boot.

---

## 🚀 Technologies Used

- Java
- Spring Boot
- Spring Web
- Spring Data JPA (if used)
- Maven
- H2 Database / MySQL (if applicable)

---

## 📌 Features

- Basic REST API setup
- CRUD operations (Create, Read, Update, Delete)
- Simple project structure using Spring Boot best practices
- Database integration (if included)

---

## ⚙️ Layers Explained

### 📍 Controller
Handles incoming HTTP requests and returns responses.

### 📍 Service
Contains the main business logic of the application.

### 📍 Repository
Communicates with the database using Spring Data JPA.

### 📍 Model
Defines the structure of database tables (entities).

### 📍 Helper
Contains reusable utility functions used across the project.
